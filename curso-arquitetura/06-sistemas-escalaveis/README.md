# Sistemas Escaláveis

Java 21+. Modelos locais e sequenciais; sem Redis, CDN ou balanceador implantados.

Partindo da **pasta do curso**:

```sh
bash 06-sistemas-escalaveis/executar.sh DemoSemCache
bash 06-sistemas-escalaveis/executar.sh DemoCache
bash 06-sistemas-escalaveis/executar.sh DemoEstadoLocal
bash 06-sistemas-escalaveis/executar.sh DemoEstadoCompartilhado
bash 06-sistemas-escalaveis/executar.sh DemoLimite
```

Cada comando compila antes de executar. Veja `roteiro.md` para ordem, previsões e causas dos resultados. `teoria.excalidraw` contém os diagramas editáveis. Links e estado da revisão estão em `../planejamento/estado-do-curso.md`.
